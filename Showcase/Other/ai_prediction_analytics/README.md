# منصة التنبؤ بالنتائج وتحليل البيانات باستخدام الذكاء الاصطناعي

## وصف المشروع
منصة متقدمة لتحليل البيانات والتنبؤ بالنتائج باستخدام خوارزميات الذكاء الاصطناعي. تم تطويرها باللغة العربية مع تصورات بيانية احترافية عالية الجودة.

## المميزات
- 🧠 نماذج ذكاء اصطناعي متقدمة للتنبؤ
- 📊 8 تصورات بيانية احترافية عالية الجودة
- 📈 تحليل الاتجاهات والأنماط المتقدم
- 🎯 توصيات ذكية مبنية على البيانات
- 🔍 تحليل إحصائي متعدد الأبعاد
- 📋 تقارير تفصيلية وإحصائيات شاملة
- 🖼️ إنتاج صور ثابتة عالية الدقة للرسوم البيانية

## التقنيات المستخدمة
- **Plotly**: الرسوم البيانية المتقدمة
- **Scikit-learn**: نماذج التعلم الآلي
- **Pandas**: معالجة وتحليل البيانات
- **Faker**: إنشاء البيانات الوهمية الواقعية
- **Kaleido**: تصدير الرسوم البيانية كصور

## طرق التشغيل

### 1. إنتاج الصور الثابتة (الطريقة المُوصى بها)
```bash
# تشغيل الملف التنفيذي
generate_plots.bat

# أو يدوياً
pip install -r requirements.txt
python static_generator.py
```

### 2. التطبيق التفاعلي (Streamlit)
```bash
pip install streamlit
streamlit run main.py
```

## الرسوم البيانية المُنتجة
1. **الاتجاهات المالية متعددة الأبعاد** - تحليل المبيعات حسب المناطق عبر الزمن
2. **مصفوفة الأداء الاستراتيجي** - تحليل المنتجات حسب المبيعات وهامش الربح
3. **التحليل الجغرافي المتقدم** - الأداء الإقليمي مع تقييمات العملاء
4. **السلاسل الزمنية والتنبؤات** - تحليل الاتجاهات مع التنبؤات المستقبلية
5. **تحليل الانحدار والارتباط** - العلاقة بين المبيعات والأرباح
6. **التوزيع الإحصائي** - توزيع المبيعات مع منحنى الكثافة
7. **الأداء المقارن متعدد المؤشرات** - مقارنة قنوات البيع بالرادار
8. **لوحة المعلومات التنفيذية** - ملخص شامل متعدد الأبعاد

## البيانات
يستخدم التطبيق بيانات وهمية واقعية تشمل:
- بيانات المبيعات والأرباح لـ 2000 معاملة
- 12 شركة سعودية وهمية
- 12 فئة منتج مختلفة
- 8 مناطق جغرافية
- مؤشرات الأداء والنمو
- تقييمات العملاء وقنوات البيع

## المخرجات
- 8 صور عالية الدقة (PNG) للرسوم البيانية
- ملف CSV يحتوي على جميع البيانات المُستخدمة
- جميع الملفات محفوظة في مجلد `static_plots`
